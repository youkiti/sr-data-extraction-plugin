## cue 01
One project equals one review. Creating a project generates a Google Sheet — the project
database — and a Drive folder for PDFs and extracted text, inside your own Google account.

## cue 02
For a new project, just enter a title and press Create.

## cue 03
Under recent projects, pick one from the list to jump straight into the main view.

## cue 04
A project shared with you by a collaborator is opened by entering its spreadsheet ID or
URL. A sheet someone else created needs a one-time grant through the picker the first time.

## cue 05
You can also select a tiab-review sheet, and the project is created automatically, carrying
over the included studies.

## cue 06
Opening a project brings up the main view. The left sidebar is the workflow itself — Home,
then import documents, protocol, schema design — top to bottom.
