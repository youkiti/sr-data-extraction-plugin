## cue 01
Before running everything, a pilot extraction tries AI on 2–3 papers first. Select the
target studies.

## cue 02
By default all fields are selected. Once you pick a model, a cost estimate appears — check
it before running.

## cue 03
Pressing Run starts the extraction. A progress bar shows the current status.

## cue 04
The verification UI is embedded right here, so you can check the results as soon as it
finishes. The AI's evidence is highlighted directly on the PDF, and you can try accept or
edit on the spot.

## cue 05
You can judge the output quality right away, revise the schema, and pilot again — a quick
back-and-forth. Past pilot runs are kept too, so you can reload and keep verifying anytime.
