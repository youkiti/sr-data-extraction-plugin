## cue 01
<!-- action: 接続方式セレクトを Gemini → OpenAI互換API に切り替え、追加で出てくる入力欄をホバー -->
接続方式は Gemini のほかにも切り替えられます。OpenAI 互換 API を選ぶと、エンドポイント URL と
API キーの入力欄に切り替わります。

## cue 02
<!-- action: reasoning effort セレクトと既定モデルセレクトをホバー -->
reasoning effort の既定値を設定すると、対応する接続先へ自動で送信されます。既定モデルは、
新しい抽出画面を開いたときの初期値になります。

## cue 03
<!-- action: レート制限のtierセレクトを切り替える -->
レート制限では、契約プランに合った tier を選ぶだけで、一括抽出のリクエスト間隔や同時実行数、
再試行が自動で調整されます。
