# 実データ抽出ベンチマーク 集計結果（プロンプト版数 17・2026-11-25）

不眠治療の SR に含まれる RCT 10 本で、AI 単独の抽出を人手の正解（gold）と比べた結果の**集計だけ**を公開するファイルです。[評価計画書](../../docs/evaluation-plan.md)の評価 B（#493、補助）として、現在の抽出プロンプト（版数 17）で測り直しました。

- 原論文の PDF・gold・個々の抽出結果は公開していません（`experiments/extraction-benchmark-real/` は `.gitignore` 対象）。
- 論文（片岡ら、準備中）の Table 3 の元データはこのファイルです。版数 9 以前の結果は [SUMMARY-20261122-corrected-gold.md](SUMMARY-20261122-corrected-gold.md) にあり、論文では補足表 S1〜S3 に載せています。
- 計画書 §6.2 のとおり、版数 9 の結果との差はプロンプトの効果としては扱いません（実行の時期もモデルの版も違い、比較を計画していないため）。
- 指標の定義は [SUMMARY-20261122-corrected-gold.md](SUMMARY-20261122-corrected-gold.md) と同じで、採点は凍結した定義（`npm run score-models`）で行いました。

## 結論

1. 項目正確度は、Gemini 3.8 Flash が 76.0%、Claude Haiku 5.5 が 52.4% でした。
2. Haiku 5.5 は、論文が報告している項目にも「報告なし」と答えることが多くありました（「報告なし」の特異度 54.1%、3.8 Flash は 93.0%）。
3. 重大エラー率は 17.8% と 15.2% で、どちらも人の確認なしで使える水準ではありません。

| モデル | 項目正確度 | 数として一致 | 表由来項目 | 未報告の感度 / 特異度 | 照合成功率 | 重大エラー率 | 逐語率 | USD/論文 | 応答時間 |

| gemini-3.8-flash（既定） | 76.0% | 77.5% | 77.9% | 82.9% / 93.0% | 87.8% | 17.8% | 75.5% | 0.068（※1） | 87.9 秒 |

- 項目正確度: run（1 論文）ごとの正確度の 10 本平均。分母は gold の全行で、AI が出さなかった行は不正解として数えます。どの論文も 123 行です。
- どの run も、gold にある行の取りこぼしと、gold に無い行の追加は 0 でした。
- 群の対応を取り直した感度分析では、どちらのモデルも値は変わりませんでした（写像が変わった run は無し）。
- ※1 2026-12-31 までの割引単価での額。
