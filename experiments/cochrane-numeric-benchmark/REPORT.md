# 評価 A の結果（Cochrane の解析データ、#356）

[評価計画書](../../docs/evaluation-plan.md)（v1.2 に逸脱の記録 v1.3・v1.4 を加えたもの）の評価 A の結果です。手順とハーネスは [README.md](README.md) にあります。このファイルには**集計だけ**を載せます。報告の本文、gold の複製、依頼、応答、引用の原文は載せません。

## 結論

1. 報告に載っている値（参照のラベルが reported）のうち、拡張が gold と同じ値を返した割合（レビュー単位の感度の平均）は、Gemini 3.8 Flash が 56.1%（95% 区間 39.6〜73.4%）、Claude Haiku 5.5 が 36.3%（21.4〜53.1%）でした。差は −19.8 ポイント（−31.7〜−9.6）で、区間は 0 をまたぎません。
2. 取りこぼしの多くは、値を返さなかったもの（24.4%・50.4%）で、誤った値（7.9%・6.2%）は少数でした。
3. CESAR のデータ抽出の中止境界（感度の点推定 92%）には、どちらも遠く及びません。拡張は人がすべての値を確かめる前提なので、この境界で拡張の合否は判定しません（計画書 §5.4）。

## 限界

- オープンアクセスのレビューと報告だけ、群ごとの二値・連続の数値だけ、PDF の文字の層がある報告だけを対象にしている
- 参照のラベルは、逐語の引用で裏付けた LLM の読み手の判定と、1 人の著者の裁定でできている。CC BY-NC では裁定の一部を別の LLM に任せ、一致した値の抜き取りの一部を確認なしで採った（計画書 v1.4）
- 各モデル 1 反復。比較は 2 モデルだけ（Sonnet 5.5 は保留）
- 1 研究の全項目を 1 依頼で送るので、本番より省略が増えうる
- 費用は API の応答のトークン数と公開の単価から計算した。請求書の額ではない
