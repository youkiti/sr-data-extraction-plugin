# 図の数値読み取りベンチ（issue #265）

結果が**図にしか載っていない**論文（平均 ± SE の折れ線、エラーバー付き棒グラフ、KM 曲線など）から、図を表に起こして抽出に渡す「図読み取りモード」を試作し、採否を決めるためのベンチです。issue #265 の 3 段階のうち、このディレクトリは現在**段階 1（公開ベンチの探索と採用基準の事前登録）**まで進んでいます。

| [PREREGISTRATION.md](PREREGISTRATION.md) | 採用基準の事前登録（指標の定義・閾値・判定手順・実行条件・費用の上限） | **案。オーナーの承認待ち**（§8 のチェックリスト） |

## 結論（段階 1）

- 採否の判定には公開ベンチを使わない。医学 RCT の図で「群ごとの平均とばらつき（SD / SE / CI の区別つき）」の正解を持つ公開データが見つからなかったため
- **結果が図にしか無い RCT 15〜20 本を集め、2 人が独立に WebPlotDigitizer で読んだ値を正解にする非公開ベンチ**を作る
- 既存の不眠 SR 10 本の非公開ベンチ（`experiments/extraction-benchmark-real/`）は、図読み取りモードを ON にしても既存の項目が悪くならないことの確認（回帰ベンチ）に使う

1. オーナーが [PREREGISTRATION.md](PREREGISTRATION.md) §8 を承認する（閾値の確定・gold を作る人の手配・費用の上限）
